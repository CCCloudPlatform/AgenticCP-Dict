# 빠른 시작

AgenticCP Dict는 **AgenticCP 전체 도메인 지식**을 한곳에 모은 백과사전/용어사전입니다.  
이 문서는 “어떤 마인드로 문서를 작성하고, 어떻게 확장할 것인지”에 초점을 맞춥니다.

## 문서를 바라보는 관점

- **제품 관점**:  
  - 사용자가 AgenticCP를 통해 무엇을 달성할 수 있는지, 어떤 가치가 있는지 설명
- **도메인 관점**:  
  - 클라우드, 워크플로우, 정책, 권한, 자동화 등 핵심 개념을 정리
- **엔지니어링 관점**:  
  - 실제 코드 구조, 모듈 간 관계, 패턴/안티패턴을 문서화

## 주요 페이지 타입

- **백과사전 항목 (Encyclopedia Entry)**  
  - 예: `Cloud Provider`, `Workflow Engine`, `Policy Evaluation`  
  - 형식:
    - TL;DR (2–3줄 요약)
    - 개념 정의
    - 설계 의도 / 등장 배경
    - 주요 사용 시나리오
    - 관련 코드/모듈 링크
    - 관련 항목 (유사 개념, 상/하위 개념)

- **용어사전 항목 (Glossary Term)**  
  - 예: `Tenant`, `Account Binding`, `Execution Context`  
  - 형식:
    - 한 줄 정의
    - 조금 더 풀어쓴 설명 (짧게)
    - 연관 태그
    - 관련 백과사전 항목 링크

## 문서 작성 시 원칙

1. **한 문서에는 한 개념만**  
2. **예시는 구체적으로, 개념은 일반화해서**  
3. **가능한 한국어 우선, 필요한 경우 원어(영문) 병기**  
4. **태그를 적극적으로 사용**해 유사 검색 품질 향상
