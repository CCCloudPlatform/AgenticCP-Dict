# 백과사전 사용 가이드

AgenticCP 백과사전은 **핵심 개념, 아키텍처, 설계 패턴**을 상세하게 설명하는 문서 모음입니다.

## 백과사전이란?

백과사전 항목은 다음과 같은 특징을 가집니다:

- **상세한 설명**: 개념의 정의, 설계 의도, 배경, 사용 시나리오를 포함합니다
- **구조화된 정보**: TL;DR → 개념 정의 → 설계 의도 → 사용 시나리오 → 관련 항목 순서로 구성됩니다
- **다이어그램과 예시**: 복잡한 개념은 다이어그램이나 코드 예시로 보완됩니다
- **교차 참조**: 관련된 다른 개념들과의 링크를 제공합니다

## 백과사전 항목 구조

각 백과사전 항목은 다음 구조를 따릅니다:

### 1. TL;DR (Too Long; Didn't Read)

- 개념을 **2-3줄로 요약**한 핵심 내용
- 빠르게 파악하고 싶을 때 먼저 읽는 섹션

### 2. 개념 정의

- 해당 개념이 **무엇인지**, 어떤 문제를 해결하기 위해 존재하는지 설명
- 도메인에서의 위치와 역할을 명확히 정의

### 3. 설계 의도 / 등장 배경

- 왜 이 개념이 AgenticCP에 도입되었는지
- 다른 접근 방식과 비교했을 때의 장단점
- 설계 결정의 근거

### 4. 주요 사용 시나리오

- 어떤 흐름에서, 누가, 어떻게 이 개념과 상호작용하는지
- 실제 사용 예시와 워크플로우

### 5. 관련 코드 / 모듈

- `AgenticCP-Core`의 관련 엔티티, 서비스, 리포지토리 등
- 코드 레벨에서의 구현 위치

### 6. 관련 항목

- 다른 백과사전 항목이나 용어사전 항목으로의 링크
- 함께 보면 이해가 깊어지는 개념들

## 백과사전 활용 방법

### 검색하기

1. **상단 검색창 사용**: 키워드로 원하는 개념 검색
2. **태그 필터링**: 관련 태그를 클릭하여 비슷한 항목 탐색
3. **네비게이션 메뉴**: 좌측 메뉴에서 카테고리별로 탐색

### 읽기 전략

- **빠른 파악**: TL;DR 섹션만 읽기
- **깊이 이해**: 전체 섹션을 순서대로 읽기
- **연속 탐색**: 하단 "관련 항목" 링크를 따라가며 개념 네트워크 탐색

### 새 항목 작성하기

백과사전에 새 항목을 추가할 때는:

1. `docs/encyclopedia/template.md`를 복사하여 시작
2. Front matter에 적절한 `title`과 `tags` 설정
3. 각 섹션을 채워넣기
4. 관련 항목과의 링크 추가
5. `mkdocs.yml`의 네비게이션에 항목 추가

## 백과사전 vs 용어사전

| 구분 | 백과사전 | 용어사전 |
|------|----------|----------|
| **목적** | 개념을 깊이 있게 이해 | 빠르게 정의 확인 |
| **길이** | 긴 문서 (500+ 단어) | 짧은 문서 (100-200 단어) |
| **구조** | TL;DR, 정의, 배경, 시나리오 등 | 한 줄 정의, 상세 설명 |
| **대상** | 아키텍처, 패턴, 복잡한 개념 | 도메인 용어, 약어, 기술 용어 |
