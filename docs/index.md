# AgenticCP Dict

**AgenticCP 생태계 전반을 한눈에 탐색할 수 있는 백과사전형 문서 허브**입니다.  
클라우드, 코어 도메인, 통합 정책 등 AgenticCP를 구성하는 개념과 패턴을 **유사 검색 기반 탐색 경험**으로 제공합니다.

!!! tip "어떻게 시작하나요?"
    1. 상단 검색창에 알고 싶은 키워드를 입력하세요.  
    2. 검색 결과에서 **가장 유사한 항목(추천 카드)**을 먼저 확인하세요.  
    3. 상세 페이지 하단의 **“관련 항목” 영역**에서 비슷한 개념을 연속적으로 탐색할 수 있습니다.

## 정보 구조

- **백과사전**:  
  - 개념, 설계 철학, 아키텍처를 **긴 글 + 다이어그램** 중심으로 설명합니다.  
  - 각 문서는 “개념 요약 → 설계 의도 → 예시 → 관련 항목” 구조를 따릅니다.

- **용어사전**:  
  - 짧고 명확한 정의, 한 줄 설명, 연관 태그로 구성됩니다.  
  - 팀 내에서 자주 사용하는 도메인 용어, 약어, 코드 레벨 용어까지 포괄합니다.

## 검색 & 유사 검색 UX (초안)

> 기술 구현이 아니라, **어떤 경험을 제공할지**에 대한 UX 초안입니다.

- 상단 전역 검색창에서 검색 시:
  - **1행: Top 매칭 결과 카드**  
    - 제목, 한 줄 설명, 유형(백과/용어), 핵심 태그 표시
  - **2행: “비슷한 항목” 수평 스크롤 카드 리스트**  
    - 검색어와 의미적으로 가까운 문서를 추천 (개념, 용어 혼합)
  - **3행 이하: 일반 검색 결과 리스트**  
    - 기존 전체 텍스트 검색 기반 결과

각 문서 우측 또는 하단에는:

- **“이 개념과 비슷한 항목”**:  
  - 같은 태그, 같은 카테고리, 자주 함께 조회되는 문서를 모아 표시
- **“함께 보면 좋은 문서”**:  
  - 실제 사용 패턴(예: 클라우드 설정 → 권한 모델) 기준 추천

## 앞으로의 확장 아이디어

- 검색 로그를 기반으로 **“사람들이 함께 많이 본 항목”** 자동 추천
- AgenticCP-Core / 다른 모듈의 코드에서 개념을 추출해 **코드 ↔ 문서 교차 링크**
- 외부 문서(블로그, RFC, 표준 문서)와도 유사 검색하여 **참고 문헌** 추천
