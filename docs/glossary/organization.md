## 한 줄 정의

AgenticCP에서 **하나의 고객 단위(회사, 기관, 팀 등)를 표현하는 사용자 집합**이자,  
정확히 **하나의 테넌트와 1:1로 매핑되는 비즈니스 주체**.

## 상세 설명

- 조직은 실제 비즈니스 상의 고객/회사/기관/팀을 표현하며,  
  해당 조직에 속한 **사용자, 관리자(Admin), 권한 체계**를 포함한다.
- 이 프로젝트에서는 **1 조직 = 1 테넌트** 규칙을 사용하므로,  
  조직이 생성/삭제되면 연결된 테넌트도 함께 생성/종료되는 것이 일반적인 흐름이다.
- 도메인 언어와 UX에서는 주로 “조직” 용어를 사용하고,  
  내부 구현·아키텍처 설명에서는 필요 시 “테넌트” 용어를 병행해 사용한다.
