# 용어사전 사용 가이드

AgenticCP 용어사전은 **도메인 용어, 약어, 기술 용어**를 빠르게 찾아볼 수 있는 참고 자료입니다.

## 용어사전이란?

용어사전 항목은 다음과 같은 특징을 가집니다:

- **간결한 정의**: 한 줄로 핵심을 전달합니다
- **빠른 참조**: 코드 리뷰나 회의 중 빠르게 용어 의미를 확인할 수 있습니다
- **상호 링크**: 백과사전 항목이나 관련 용어로 연결됩니다
- **태그 기반 분류**: 카테고리별로 용어를 그룹화합니다

## 용어사전 항목 구조

각 용어사전 항목은 다음 구조를 따릅니다:

### 1. 한 줄 정의

- 용어의 **핵심 의미를 한 문장**으로 요약
- 가장 중요한 정보를 먼저 제공

### 2. 상세 설명

- 한 줄 정의를 보완하는 추가 설명
- 예시, 사용 맥락, 주의사항 등을 포함할 수 있음
- 필요시 목록이나 표로 구조화

### 3. 관련 항목

- 해당 용어와 관련된 다른 용어사전 항목
- 더 자세한 설명이 필요한 경우 백과사전 항목으로의 링크
- 함께 사용되는 용어들

## 용어사전 활용 방법

### 검색하기

1. **상단 검색창 사용**: 용어명이나 약어로 검색
2. **알파벳 인덱스**: 용어 인덱스 페이지에서 알파벳순으로 탐색
3. **태그 필터링**: 관련 태그를 클릭하여 비슷한 용어 탐색

### 읽기 전략

- **빠른 확인**: 한 줄 정의만 읽고 넘어가기
- **상세 이해**: 상세 설명과 관련 항목까지 읽기
- **연속 탐색**: 관련 항목 링크를 따라가며 용어 네트워크 탐색

### 새 항목 작성하기

용어사전에 새 항목을 추가할 때는:

1. `docs/glossary/template.md`를 복사하여 시작
2. Front matter에 적절한 `title`과 `tags` 설정
3. 한 줄 정의와 상세 설명 작성
4. 관련 항목 링크 추가
5. `mkdocs.yml`의 네비게이션에 항목 추가 (선택사항)

## 용어사전 vs 백과사전

| 구분 | 용어사전 | 백과사전 |
|------|----------|----------|
| **목적** | 빠르게 정의 확인 | 개념을 깊이 있게 이해 |
| **길이** | 짧은 문서 (100-200 단어) | 긴 문서 (500+ 단어) |
| **구조** | 한 줄 정의, 상세 설명 | TL;DR, 정의, 배경, 시나리오 등 |
| **대상** | 도메인 용어, 약어, 기술 용어 | 아키텍처, 패턴, 복잡한 개념 |
