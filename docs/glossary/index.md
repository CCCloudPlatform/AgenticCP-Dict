# 용어 인덱스

AgenticCP에서 자주 등장하는 **도메인 용어, 약어, 기술 용어**를 모아둔 페이지입니다.

## 예시 용어 그룹

- A
  - `Account`
  - `Account Binding`
- C
  - `Cloud Provider`
  - `Context`
- T
  - `Tenant`

각 용어 페이지는 다음 템플릿을 따르는 것을 권장합니다.

```markdown
---
title: Tenant
tags:
  - tenant
  - core-domain
---

# Tenant

## 한 줄 정의

하나의 조직/고객을 대표하는 논리적 구분 단위.

## 관련 항목
```
