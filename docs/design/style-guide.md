# 디자인 & 톤 가이드

AgenticCP Dict는 **읽기 편한 백과사전 경험**을 목표로 합니다.

## 비주얼 디자인 원칙

- **여백 중심 레이아웃**
  - 본문 폭은 너무 넓지 않게 (약 70–80자)
  - 섹션 사이에 충분한 상/하 패딩

- **강조는 색보다 구조로**
  - 제목 계층(H1, H2, H3)을 명확히 사용
  - 중요한 정의/경고는 `!!! info`, `!!! warning` 블록으로 표현

- **다크 모드 지원**
  - 라이트/다크 전환 토글 제공 (이미 `mkdocs.yml`에 설정됨)

## 콘텐츠 톤 & 스타일

- **친절하지만 과도하게 캐주얼하지 않게**
- **한 문단에 하나의 메시지**
- 전문 용어는 처음 나올 때 원어(영문)를 함께 표기

## 컴포넌트 사용 패턴

- **정의 강조**

  ```markdown
  !!! info "정의"
      이 개념의 공식적인 정의를 여기에 작성합니다.
  ```

- **주의/제약 사항**

  ```markdown
  !!! warning "주의"
      이 개념을 사용할 때 반드시 알아야 하는 제약/주의점을 작성합니다.
  ```

- **탭으로 비교하기**

  ```markdown
  === "AgenticCP 관점"
      여기에는 AgenticCP 입장에서의 설명을 작성합니다.

  === "일반 클라우드 관점"
      여기에는 일반적인 클라우드 관점의 설명을 작성합니다.
  ```
